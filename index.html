  • Menginstal dan mengonfigurasi VS Code beserta ekstensi esensial
  • Membuat akun GitHub dan repository pertama
  • Membuat profil GitHub: foto, bio, pin repository

  • Eksplorasi DevTools: inspect element, console

GitHub repo aktif + file HTML pertama. Rubrik: profil lengkap, commit berhasil.

Tag semantik (header, nav, main, section, footer), form, tabel, multimedia embed
HTML

  • Membuat form dengan berbagai tipe input dan validasi HTML
  • Menyematkan gambar, audio, dan video pada halaman
  • Buat halaman profil diri: foto, biodata, hobi (HTML murni)
  • Buat halaman form pendaftaran dengan 8+ field berbeda
  • Validasi HTML dengan W3C Validator

2 file HTML valid W3C di GitHub. Rubrik: semantik benar, form lengkap.

CSS

  • Menggunakan flexbox untuk layout baris dan kolom
  • Mengimplementasikan variabel CSS (custom properties)
  • Styling halaman profil dari minggu lalu dengan CSS terpisah
  • Buat card komponen: avatar + nama + deskripsi + tombol
  • Buat layout 3-kolom sederhana dengan flexbox
 📁 Tugas
Halaman terstyling + card komponen. Rubrik: penggunaan flexbox, variabel CSS.
4
CSS Responsive & Grid
Media query, CSS Grid, mobile-first design, viewport meta, gambar responsif
Responsive
  • Menerapkan mobile-first design dengan media query
  • Membangun layout grid multi-kolom yang responsif
  • Memastikan tampilan konsisten di berbagai ukuran layar
  • Buat halaman galeri foto responsif (CSS Grid auto-fit)
  • Test responsivitas di DevTools (mobile/tablet/desktop)
  • Perbaiki layout profil agar mobile-friendly
 📁 Tugas
Galeri responsif yang lulus tes 3 breakpoint. Rubrik: layout benar, tidak overflow.
